# Cricket World

GitHub Pages-ready single-player website.

Folder structure:
- index.html
- game.html
- auction.html
- css/style.css
- js/game.js
- js/auction.js

Games:
- Odd If Cricket: 1 wicket
- Quick Cricket: 5 wickets, 10 overs
- Real Cricket: 10 wickets, 20 overs

IPL Auction:
- 10 team choices
- 3 computer opponents
- Bids: ₹1 Cr, ₹2 Cr, ₹5 Cr, ₹10 Cr, Skip
- Requested player categories
- Final 4-team squad summary with purchase prices
