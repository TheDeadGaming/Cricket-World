# Cricket World — GitHub Ready

Static single-player Cricket World website. No Flask or Python required.

## Upload to GitHub
1. Extract the ZIP.
2. Create a GitHub repository.
3. Upload all files and folders inside.
4. Go to Settings → Pages → Deploy from branch → `main` → `/ (root)` → Save.

## Included
- Odd If Cricket — 1 wicket
- Quick Cricket — 5 wickets, 10 overs
- Real Cricket — 10 wickets, 20 overs
- IPL Auction — 10 team choices
- User plays against 3 computer-operated teams
- If user selects MI, RCB or CSK: the other two plus GT are opponents
- Otherwise: MI, RCB and CSK are opponents
- Auction bids: ₹1 Cr, ₹2 Cr, ₹5 Cr, ₹10 Cr, Skip
- Requested player categories, including Ben Stokes, Ishan Kishan, Ravichander Ashwin and Dale Styne
- No Finishers category
- Final description lists all 4 teams, categories and purchase prices
